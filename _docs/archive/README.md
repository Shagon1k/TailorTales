# Planning and Design Archive

This directory preserves the original phased delivery history:

- [ROADMAP.md](ROADMAP.md) — completed phase plan, closeout notes, and the Post-MVP migration record.
- [DESIGN.md](DESIGN.md) — design-review decisions captured during the phased build.

These files are historical artifacts, not operational documentation. Current system behavior
lives in the durable `_docs/` documentation and code. Active and deferred delivery scope lives
only in [GitHub Project 2](https://github.com/users/Shagon1k/projects/2).
